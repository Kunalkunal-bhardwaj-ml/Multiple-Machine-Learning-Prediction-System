# Diabetes Prediction

This project uses machine learning to predict the possibility of diabetes based on medical input features.

## Files Included
- `Diabetes_Prediction.ipynb` – Notebook for data analysis, preprocessing, model training, and evaluation.
- `Diabetes_model.sav` – Saved machine learning model used for prediction.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn

**Purpose:** To learn machine learning model training and diabetes prediction.
