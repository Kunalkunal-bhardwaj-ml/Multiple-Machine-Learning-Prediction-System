# Heart Disease Prediction

This project uses machine learning to predict the possibility of heart disease from medical input features.

## Files Included
- `Heart_Disease_Prediction.ipynb` – Notebook for data preprocessing, model training, and evaluation.
- `heart_disease_model.sav` – Saved machine learning model.
- `heart_disease_encoders.sav` – Saved encoders used to transform categorical inputs.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn

**Purpose:** To learn medical data preprocessing and machine learning prediction.
