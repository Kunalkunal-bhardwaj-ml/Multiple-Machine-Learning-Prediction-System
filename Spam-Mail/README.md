# Spam Mail Detection

This project uses machine learning and text vectorization to classify messages or emails as spam or not spam.

## Files Included
- `Spam_Mail_Prediction.ipynb` – Notebook for text preprocessing, feature extraction, model training, and evaluation.
- `spam_mail_model.sav` – Saved machine learning model.
- `spam_mail_vectorizer.sav` – Saved TF-IDF vectorizer used to transform text into numerical features.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- TF-IDF Vectorizer

**Purpose:** To learn text preprocessing, feature extraction, and spam classification.
